Privacy Policy

Updated 20 October 2026. This notice describes this version of WhatIf.

What stays in your browser

Built-in scenarios run in your browser and do not send your question to an AI provider. Up to 50 simulation records, including questions, assumptions, controls and outcomes, are saved in local storage on this browser. Other people using the same browser profile may be able to see them. A random browser identifier is used for the history display; it is not hardware recognition or authentication.

Consent acknowledgements and intro completion are stored for the browser session. When storage is unavailable, history is held in memory and may be lost when the page closes.

Custom questions and Google Gemini

After you acknowledge the pre-simulation notice and submit a custom question, the WhatIf server sends that question to Google's Gemini API to generate three illustrative strategies. The server does not send your saved history or browser identifier. Do not include passwords, API keys, or sensitive personal information in a question.

Google processes requests under the API account's applicable terms. Retention, use for product improvement and account settings depend on that account; this app cannot promise deletion from Google's systems. Review Gemini API terms and Google's privacy policy.

Server processing and third parties

The bundled server keeps connection addresses in memory for request limiting for up to one hour, and until the next custom request clears an expired window. A restart clears those counters. It logs request IDs and status codes for server errors, without questions, AI responses or API credentials. It does not persist questions or AI results on disk. Hosting and reverse-proxy providers may maintain their own access logs.

Google Fonts and the cdnjs animation library receive network requests when the interface loads. Those providers and your hosting provider may receive your IP address and request metadata. This app adds no analytics or advertising trackers.

Deleting your local data

Use the clear-history control on the Chat History page, or remove this site's storage in your browser settings. Clearing browser storage also removes the local identifier and session acknowledgement. This does not delete records independently held by Google or your hosting provider. Closing the app stops further requests; cancelling a request may not stop processing already started by Google.

Operator information

This source distribution does not specify an operator contact or a hosting-log retention policy. The deployment owner must publish those details before a public launch. Do not use public issue trackers to disclose private questions or credentials.
